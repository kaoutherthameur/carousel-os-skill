# Default design system

Use this as the default only. Replace it with the user's brand rules whenever they provide them.

## Visual direction

Create crisp editorial slides: midnight navy fields, cloud-white space, coral emphasis, and sky-blue information signals. The style should feel like a contemporary magazine spread with energetic diagrammatic cues, not a generic productivity template.

- Use navy or cloud white as the dominant field.
- Use coral for the single strongest action, contrast, or warning.
- Use sky blue for labels, numbers, paths, and secondary structure.
- Use mist blue for cards and quiet dividers.
- Avoid gradients, chrome effects, soft beige, neon overload, and decorative blobs.

## Type and layout

- Keep cover titles to 3–10 words and make them the largest element.
- Maintain a 60 px side safe area and generous whitespace.
- Use high contrast and a maximum of two type weights per slide.
- Use a small optional footer handle only when the user provides one.
- Prefer a strong single metaphor, chart, card system, or screenshot over a collection of unrelated icons.

## Image direction

If an image is useful, use a bold editorial crop, tactile object, unexpected physical metaphor, or clean product-like still life. Keep it distinct from the user's references and leave a protected text field. Generate image bases without lettering; add the exact title afterward.

## Brand overrides

When custom branding is supplied, retain the workflow but replace colors, typography, imagery, logo/handle placement, tone, and CTA language. Never retain the default system merely because it is convenient.
