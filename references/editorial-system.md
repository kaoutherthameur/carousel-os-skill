# Editorial system

## Source hierarchy

Use the user's supplied brief and source material first. When facts may change, browse and prefer primary sources. Record each material claim with its source URL, checked date, and confidence in `sources.md`.

## Story architecture

1. Cover: clear promise plus a visual interruption.
2. Second-chance hook: a self-contained alternate entry point with an open loop.
3. Teaching: one distinct idea per slide.
4. Synthesis: a saveable checklist, framework, comparison, or recap.
5. CTA: one next action on the last slide only.

Write for scanning: short headings, concrete verbs, and a visible progression. Prefer a useful tension over vague inspiration. Make the caption expand the carousel instead of restating it.

## Captions

Write a natural caption in the user's requested voice and language. Start with the core promise, add context or a practical example, include sources when appropriate, and finish with one direct CTA. Use only relevant hashtags, if any.
