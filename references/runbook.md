# Runbook

1. Create a local run folder and preserve the user's inputs.
2. Establish the topic, audience, one promise, action, and claim ledger.
3. Draft the cover, second hook, teaching arc, synthesis, CTA, and caption.
4. Create or select text-free imagery only where it improves comprehension.
5. Add exact cover text with `scripts/overlay_title.py`; use the same type treatment on the interiors.
6. Fill a copy of `templates/carousel.json`, render it, and inspect the contact sheet.
7. Correct any factual, crop, hierarchy, typography, or packaging defect and rerender.
8. Write the delivery artifacts, package the run, and validate it.

If a supplied image or source is unusable, state the limitation and continue with a safe alternative. Do not silently invent a source or claim.
